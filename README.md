# MR Construção — Front-End CRUD

Aplicação web front-end desenvolvida em React e TypeScript para gestão de **Clientes** e **Produtos** integrada à API da **MR Construção**.

## Autor

* **Nome:** Carlos Alves do N. Neto
* **Curso / Turma:** Front-End (FFE — Turma 2025–2026)
* **Repositório:** [github.com/Carlos-Ne/mr.-constru-o](https://github.com/Carlos-Ne/mr.-constru-o)

## Funcionalidades

* **Clientes:** listagem, criação (`POST`), edição (`PUT` com suporte a identificadores em texto/UUID) e remoção (`DELETE`).
* **Produtos:** listagem, criação (`POST` alinhado ao contrato da API), edição (`PUT`) e remoção (`DELETE`).

## Tecnologias utilizadas

* React + TypeScript + Vite
* React Router DOM
* RTK Query / integração REST com a API MR Construção
