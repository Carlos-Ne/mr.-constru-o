# MR Construção — Front-End CRUD

Aplicação web front-end desenvolvida em React e TypeScript para gestão de **Clientes** e **Produtos** integrada à API da **MR Construção**[cite: 15, 18].

## Autor

* Nome: Carlos Alves do N. Neto
* Curso / Turma: Front-End (FFE — Turma 2025–2026)[cite: 19]
* Repositório: [github.com/Carlos-Ne/mr.-constru-o](https://github.com/Carlos-Ne/mr.-constru-o)[cite: 18]

## Funcionalidades

* **Clientes:** listagem, criação (`POST`), edição (`PUT` com suporte a identificadores em texto/UUID) e remoção (`DELETE`)[cite: 4, 7, 8, 15].
* **Produtos:** listagem, criação (`POST` alinhado ao contrato da API), edição (`PUT`) e remoção (`DELETE`)[cite: 9, 14, 15, 16, 17].

## Tecnologias utilizadas

* React + TypeScript + Vite[cite: 1, 15]
* React Router DOM[cite: 15]
* RTK Query / integração REST com a API MR Construção[cite: 15]

## Como executar o projeto

1. Entre na pasta do front-end:
   npm install
   npm run dev
